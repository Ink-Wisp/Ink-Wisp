## 从一块板开始

我是 **Inkwisp**，专注嵌入式系统与边缘设备。

从原理图、板级调试和固件开始，逐步连接驱动、协议、Linux 与应用。我关心软硬件各层如何协同，让设备稳定运行、便于定位问题，也能持续扩展。

```text
inkwisp@lab:~$ trace --from board --to application
硬件 ── 固件 ── 协议 ── Linux / Edge ── 应用
每一段都可测量、可调试、可维护。
```
