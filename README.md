## 从信号到系统

你好，我是 **Inkwisp**，一名专注嵌入式系统与边缘设备的开发者。

我喜欢从一块板开始：画原理图、调外设、写驱动与协议，再把 Linux、应用和网络连接起来，让硬件真正成为一套可以运行的系统。

```text
Inkwisp@github:~$ cat /etc/focus
MCU · Embedded Linux · IoT · Edge Computing

Inkwisp@github:~$ echo $WORKFLOW
board -> driver -> protocol -> application
```

## 工作方向

| 层级 | 关注点 |
| :--- | :--- |
| **01 / DEVICE** | MCU、板级开发、外设驱动与实时系统 |
| **02 / SYSTEM** | Embedded Linux、系统构建、设备管理与调试 |
| **03 / LINK** | 串行总线、现场协议、网络通信与消息传输 |
| **04 / APPLICATION** | Qt 上位机、Android 终端、Python 工具与可视化界面 |
